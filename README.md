# Microstructure-ML-Grain-Diffusion
Developed a hybrid deep generative modeling framework for computational materials science, leveraging a custom conditional diffusion U-Net to learn grain-boundary distance representations from simulated microstructures. The architecture integrates spatially resolved thermal fields, manufacturing process parameters (RPM, pressure, dwell time), cosine-scheduled diffusion, DDIM-based inference, and k-nearest-neighbor morphology calibration. A stochastic Voronoi tessellation module reconstructs discrete grain geometries, enabling probabilistic multi-sample microstructure generation and quantitative evaluation of boundary density and spatial texture characteristics under varying processing conditions.
